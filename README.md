# ciel

A sky behind your Claude Code conversations in the Claude desktop and mobile apps. Its gradient follows the time of day: deep night with a few twinkling stars, first light, sunrise, a blue daytime sky with soft haze drifting at the bottom, golden hour, dusk, and back to night. The colors blend from one moment to the next and move along every five minutes, using your computer's local time.

The app's panels stay frosted over the sky, so the conversation stays easy to read.

Sunrise and sunset times change with the seasons. They follow approximate times for Paris, so the sky matches France best.

With "reduce motion" turned on, the haze and stars stay still.

## Install

In a terminal session of Claude Code:

```
/plugin install ciel --marketplace Jean-Berthelier/claude-ciel
```

From a shell:

```bash
claude plugin install ciel --marketplace Jean-Berthelier/claude-ciel
```

In the Claude desktop app: click + next to the prompt box, then Plugins, Add marketplace with `Jean-Berthelier/claude-ciel`, then Add plugin.

## Remove

```bash
claude plugin disable ciel
```
